3. **Memory Leak in `_rgbaCache`**:
   - In `src/game/draw.ts:27-35`:
     ```typescript
     const _rgbaCache = new Map<string, string>();
     export function rgba(hex: string, a: number): string {
       const key = `${hex}_${a}`;
       const cached = _rgbaCache.get(key);
       if (cached) return cached;
       const [r, g, b] = hexToRgb(hex);
       const res = `rgba(${r},${g},${b},${a})`;
       _rgbaCache.set(key, res);
       return res;
     }
     ```
   - Throughout `draw.ts`, `rgba(hex, a)` is called with floating-point values generated by continuous trigonometric functions (e.g. `rgba("#38bdf8", alpha * 0.16)`, `rgba("#22d3ee", (0.3 + 0.2 * pulse) * (opts.cloakAlpha ?? 1))`, `vPulse = 0.75 + 0.25 * Math.sin(t * 8)`).
   - Because `a` is an unrounded 64-bit IEEE 754 float, `key = `${hex}_${a}`` produces virtually unbounded unique strings across continuous gameplay frames. The `_rgbaCache` Map grows indefinitely without eviction or quantization, causing heap memory to grow by ~67 MB across 10,000 frames.

## 2. Logic Chain

1. **Acceptance Criteria**: The project specification (`ORIGINAL_REQUEST.md` §Acceptance Criteria) strictly requires:
   > "游戏 Canvas 主循环稳定 60 FPS 运行，各帧渲染与光照计算无性能卡顿或内存泄漏" (Stable 60 FPS without performance stutter or memory leaks).
2. **Observation vs Invariant**: `tests/stress_m1_character_draw_benchmark.mjs` executes 160,000 draw calls over 10,000 frames (representing ~2.7 minutes of 60 FPS gameplay with 16 entities). The assertion `heapDiffMB < 30.0` failed with `67.28 MB`.
3. **Root Cause**: The un-quantized `_rgbaCache` in `src/game/draw.ts` acts as an unbounded string table leak when fed continuous sine-wave alphas.
4. **Resolution**: Quantizing alpha to 2 decimal places in `rgba()` (e.g., `const aQ = Math.round(a * 100) / 100; const key = `${hex}_${aQ}`;`) limits the maximum cache size per hex code to 101 entries, instantly eliminating the memory leak while retaining 100% visual fidelity and passing the benchmark.

## 4. Conclusion & Verdict

**Verdict**: **`REQUEST_CHANGES`**

### Summary of Findings:
- **[Major] Finding 1: Unbounded `_rgbaCache` Memory Leak in `src/game/draw.ts`**
  - **Where**: `src/game/draw.ts`, lines 27–35 (`export function rgba(hex: string, a: number)`)
  - **Why**: Sine-wave modulated alpha values create millions of unique string keys in `_rgbaCache`, causing an unbounded memory leak that violates the zero-leak acceptance criterion and fails `tests/stress_m1_character_draw_benchmark.mjs`.
  - **Suggested Fix**:
    ```typescript
    const _rgbaCache = new Map<string, string>();
    export function rgba(hex: string, a: number): string {
      const aQ = Math.round(a * 100) / 100;
      const key = `${hex}_${aQ}`;
      const cached = _rgbaCache.get(key);
      if (cached) return cached;
      const [r, g, b] = hexToRgb(hex);
      const res = `rgba(${r},${g},${b},${aQ})`;
      _rgbaCache.set(key, res);
      return res;
    }
    ```
    *(Optionally also add `if (_rgbaCache.size > 2048) _rgbaCache.clear();` as a safety guard).*
